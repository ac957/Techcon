# TechCon Website

## Overview

TechCon 2023 is a multi-page conference website developed for a
fictional technology conference. The website provides visitors with
information about the conference, speakers, schedule and registration.

The project was developed using HTML, CSS and JavaScript, with a focus
on creating a simple, accessible and easy-to-navigate website.

The project was originally developed in 2023 and has since been
revisited to clean up the code, improve the file structure and make the
project easier to run and maintain.

------------------------------------------------------------------------

## What the Project Does

The TechCon 2023 website provides several pages and features:

-   **Home Page** - Introduces the TechCon 2023 conference and provides
    an overview of the event.
-   **Registration Page** - Allows users to enter their details to
    register for the conference.
-   **Contact Page** - Provides information for contacting the
    conference organisers.
-   **Schedule Page** - Displays the conference schedule and allows
    users to view different sessions.
-   **Speakers Page** - Provides information about the speakers
    attending the conference.
-   **Navigation Menu** - Allows users to move between the different
    pages of the website.
-   **Form Validation** - Uses JavaScript to validate information
    entered into the registration form.
-   **Images and Conference Content** - Uses images and visual content
    to provide information about the conference and its speakers.

## Why the Project Is Useful

The project demonstrates how a multi-page website can be designed and
developed for a technology event.

-   Learn about the conference.

-   View the conference schedule.
-   Register for the event.
-   Find contact information.

# How to Get Started

## Requirements

You will need:

-   A computer.
-   A modern web browser such as Google Chrome, Microsoft Edge or
    Firefox.
-   Visual Studio Code.
-   The **Live Server** extension for Visual Studio Code.

No database, backend server or external API is required to view the
website.

## 1. Download or Clone the Repository


## 2. Open the Project in Visual Studio Code



## 3. Install Live Server

The recommended way to run this project is using the **Live Server**
extension.

In Visual Studio Code:

1.  Select the **Extensions** icon.
2.  Search for `Live Server`.
3.  Install the Live Server extension by **Ritwick Dey**.

Live Server creates a local development server so that the website can
be viewed correctly in a browser.

## 4. Run the Website Using Live Server

1.  Open the `html` folder.
2.  Open `Index.html`.
3.  Right-click inside the HTML file.
4.  Select **Open with Live Server**.

The website should open automatically in your browser.

The address will normally look similar to:

``` text
http://localhost:5500/html/Index.html
```

or:

``` text
http://127.0.0.1:5500/html/Index.html
```

The exact port number may vary depending on the Live Server
configuration.

## 5. Why Live Server Is Recommended

The project can technically be opened by double-clicking `Index.html`,
but using Live Server is recommended.

Live Server provides a local web server which makes it easier to test
the website in an environment similar to a real website. It also
automatically refreshes the browser when changes are made.


## 8. Running the Project Without Live Server

The website can also be opened without Live Server:

1.  Open the project folder.
2.  Open the `html` folder.
3.  Double-click `Index.html`.
